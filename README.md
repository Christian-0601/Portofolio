# Christian Portfolio

A modern personal portfolio website built with React, TypeScript, Vite, and Express. This project showcases my background, skills, certifications, projects, and contact information in a clean, professional layout.

## Features

- Responsive multi-section portfolio layout
- Hero section with profile and personal branding
- Skills, project, certificate, and journey sections
- Contact section with WhatsApp and social links
- Clean dark neo-brutalist styling
- Production-ready Vite + Express setup

## Tech Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS
- Express
- Node.js

## Getting Started

### Prerequisites

- Node.js 18+
- npm

### Install dependencies

```bash
npm install
```

### Run locally

```bash
npm run dev
```

Then open the app in your browser at the local Vite URL shown in the terminal.

### Production build

```bash
npm run build
```

### Start production server

```bash
npm run start
```
